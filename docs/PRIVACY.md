# 隐私说明

妙妙阅读不要求注册账号，项目没有开发者运营的文档上传、云同步或使用人数统计服务。

- 导入的文档、识别缓存、阅读进度和标注保存在应用数据目录。
- 英文 OCR 使用随应用安装的 ML Kit 模型。相关组件由 Google 提供，遵循其服务条款。
- 单词发音使用手机选择的 Android TTS 引擎；语音数据、联网行为和隐私设置由该引擎管理。
- Android 系统可能按手机设置备份应用数据。系统备份并非本项目提供的云同步。
- 只有用户主动导出时，应用才将 CSV 或 ZIP 写到用户选择的位置。ZIP 备份可能包含完整原文，请自行决定与谁分享。
- 在 GitHub 提交反馈时，请使用可公开的示例，遮盖私人文档、文件名或账号信息。
