# 妙妙阅读 0.2.3 · 长按反馈修复

- 屏蔽阅读 WebView 提前触发的系统长按震动，由选词逻辑在约 1 秒、已准备好标注后触发一次反馈；震动后立即松手即可打开弹窗。
- 松手使用输入事件的时间戳校验长按时长。到达阈值而计时回调尚未执行时，直接完成选词，不再要求继续按住。
- 原始 PDF 页同样补齐长按阈值与松手事件恰好同时发生时的处理。
- 保留轻点中央唤醒工具栏、长按后拖动选短语、左右滑动翻页、双指缩放及原有标注数据。
- 包名及原签名不变；versionCode 递增为 5。可用于覆盖同签名的 0.2.1 / 0.2.2，真实设备升级与触感仍需实测。

## 妙妙阅读 0.2.2 · 首个公开试用版

为希望边读英文、边记录中文理解的 Android 使用者提供试用。

- PDF / TXT 阅读及扫描 PDF 英文 OCR。
- 墨绿与暖白界面，轻点中央唤出工具栏，长按约 1 秒选词，左右滑动翻页。
- 六色高亮、固定红色单线 / 双线 / 波浪线，可修改中文注释。
- 生词 CSV 导出含中文注释和所在原句；系统英语单词发音。
- 本地阅读备份与恢复。

公开版改用原创试读及 ECDICT 通用词典，不分发私人雅思词库、剑桥试题或签名私钥。原包名保留；维护者签署的正式包沿用原签名，版本号递增。

请在 Issues 中选择“使用反馈”，告诉我们是否愿意继续使用，以及最影响体验的问题。当前没有账号或多设备同步。

已通过 Java 编译、9 项 JUnit、手势脚本、公开内容检查与 APK 原签名核验。Android 真机触控、发音、导出及覆盖安装尚未实测，详情见 `docs/VERIFICATION.md`。
